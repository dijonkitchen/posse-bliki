# 2026-10-18 — A separate now page

- Date: 2026-10-18
- Status: Proposed
- Raised by: JC, who asked whether to add a now page or fold it into the
  résumé.

## Context

A [now page](https://nownownow.com/about) says what someone is focused on
at the moment. The résumé (ADR 2026-10-16-resume-page) is a stable record
that changes a few times a year; a now page is dated and changes often.

## Decision

- `content/now.md` renders at `/now/`, the conventional address, so the
  nownownow directory and readers who guess the URL find it.
- It opens with the month it was last updated, and links to the résumé.
- It is not in the site nav; the résumé and About link to it.

## Consequences

- Updating what JC is doing doesn't touch the résumé, and the résumé
  doesn't go stale when focus shifts.
- The "Updated" line is written by hand, so it can lag the content.

## Alternatives considered

- **A "Now" section on the résumé.** One page fewer, but it mixes a
  dated snapshot into a stable record and loses the `/now/` convention.
- **Put Now in the nav.** A fifth nav link crowds the header on phones
  for a page fewer people look for.
