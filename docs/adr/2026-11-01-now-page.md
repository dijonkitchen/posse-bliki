# 2026-11-01 — A now page, after Derek Sivers

- Date: 2026-11-01
- Status: Accepted; the footer link is superseded by [2026-11-05-now-in-the-header](2026-11-05-now-in-the-header.md)
- Decided by: JC, asking for "a now page with homage", pointing at
  <https://nownownow.com/about>.

## Context

Derek Sivers started the [/now page](https://nownownow.com/about) in
2015: one page on your own site that says what you're focused on now,
so people who haven't talked to you in a while can catch up, and you
have a nudge to decide what matters. Thousands of personal sites have
one, and nownownow.com lists them. It's an IndieWeb habit that fits a
bliki: a page you own and keep editing, not a feed.

A now page goes stale quietly. A reader can only trust it if they can
see when it was last changed.

## Decision

- `content/now.md` is an ordinary page at `/now/`, written in Markdown
  like everything else in `content/`.
- It must have an `updated` date. The build fails without one and shows
  it under the title as "Updated <date>" (Holocene year on the page, ISO
  in `datetime`, like every other date).
- The page ends with the homage: it links nownownow.com/about and Derek
  Sivers's own now page, and thanks the /now movement. The harness checks
  the credit and the nownownow.com/about link are there.
- Every page's footer links "Now" when the page is published, the same
  way it links the blogroll. The header nav stays Notes, About, Colophon.
- The first version is drafted only from what JC's posts, About page and
  this repo already say. What they don't say is marked `TODO(JC)` for JC
  to fill in, and the note stays `draft: true` until then. The harness
  fails if `TODO(JC)` shows up on any published page.

## Consequences

- Updating the page is editing one Markdown file and bumping `updated`.
- Nothing goes live until JC removes `draft: true`, so merging this
  doesn't publish placeholders.
- Once live, the page can be submitted to nownownow.com.

## Alternatives considered

- **A header nav link.** Many now pages sit in the main menu. The header
  is the same in all twenty styles and already full on phones; the
  footer is where the site's other "about the author" links live. Moving
  it is a one-line change if JC wants it there.
- **Date from the Git history.** No editing step to forget, but the build
  reads files, not Git, and a typo fix shouldn't count as an update.
- **Homage in the template.** Harder to remove by accident, but it would
  be the only page text outside `content/`, and JC can't edit it in
  Obsidian.
