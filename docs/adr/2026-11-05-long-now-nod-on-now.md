# 2026-11-05 — A nod to the Long Now on the now page

- Date: 2026-11-05
- Status: Accepted
- Decided by: JC, asking "worth making a nod to long now for now page?"
  and saying yes to adding it.

## Context

A [now page](2026-11-01-now-page.md) is about this stage of life, months
at most. The [Long Now Foundation](https://longnow.org) thinks in the
next 10,000 years, and it's already why this site shows
[Holocene years](2026-10-11-holocene-years-on-the-page.md). The two
names make a natural pair.

## Decision

- `content/now.md` ends its "About this page" section with one line:
  "This is just my now. For the long now, see the Long Now Foundation,
  which also inspired this site's Holocene years", linking
  longnow.org and the colophon, which explains the years.
- It's plain Markdown in the page, like the nod to Derek Sivers, so JC
  can reword or drop it in Obsidian.
- No Long Now style five-digit years (02026) on the page: the site
  already shows Holocene years (12026), and two ways of writing a year
  on one page would only confuse.
- The harness checks the page still links longnow.org.

## Consequences

- The page credits both ideas it draws on: Derek Sivers for the now,
  the Long Now for the long view.
- The colophon and the now page both point at the Long Now, each for
  its own reason.

## Alternatives considered

- **Long Now dates on the now page** ("Updated 02026-11-05"). On-theme,
  but it would clash with the Holocene years used everywhere else.
- **No nod.** The colophon already credits the Long Now; the now page
  is where the joke lands, though.
