2020 to present · Remote

- Improved profit margins 507% in 12 months with LangChain generative AI

  automated tests, to a new TypeScript NestJS app with a GraphQL API and
  a simpler React Hooks web app, helping scale note documentation by 412%.
- Championed instrumentation and metrics across 103 serverless functions
  and 4 core services, bringing dashboards and alerts for errors,
  performance and data-driven decisions.
- Synced hotword events with dynamic slices of video streams to improve
  the user experience.
- Optimized video transcription with just-in-time serverless event
  processing, relieving back pressure.
- Streamlined continuous integration and deployment for faster feedback
  from production with real data.
- Interviewed 12% of new candidates and sat on the hiring committee.

### Software Engineer, Dividend Finance

2018 to 2020 · San Francisco, CA

  end-to-end smoke tests to continuous integration.
